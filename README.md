# FarmWise Africa - free farm tools + ebooks
Eleventy site. Build: npx @11ty/eleventy  Publish: _site  (netlify.toml already set)
- Tools: /tools/livestock-feed-calculator/<country>/ and /tools/crop-input-calculator/<country>/ in 5 languages (/fr /ar /pt /sw prefixes).
- Texts and translations: src/_data/i18n.json. Countries and currencies: src/_data/countries.json.
- Feeding and crop tables: src/js/feed.js and src/js/crop.js (please review the numbers with a local extension officer).
- Edit ebooks and blog posts from /admin (Decap CMS).
